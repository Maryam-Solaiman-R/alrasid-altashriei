# الراصد التشريعي — v1.6 Deployment Candidate

هذه النسخة تجهز المشروع للنشر الفعلي.

## المصادر الأساسية الظاهرة للمستخدم
- هيئة الخبراء بمجلس الوزراء
- المركز الوطني للوثائق والمحفوظات
- الديوان العام للمحاسبة
- وزارة المالية
- وزارة الموارد البشرية والتنمية الاجتماعية
- هيئة المحتوى المحلي والمشتريات الحكومية
- هيئة كفاءة الإنفاق والمشروعات الحكومية
- هيئة الحكومة الرقمية
- الهيئة الوطنية للأمن السيبراني
- الهيئة السعودية للبيانات والذكاء الاصطناعي (سدايا)

وجريدة أم القرى مصدر نشر رسمي أساسي.

## معنى «جميع الجهات»
ليس حصرًا للقائمة السابقة. عند اختياره يسمح المحرك باكتشاف مصادر حكومية سعودية رسمية أخرى، مع التحقق من المصدر والمحتوى قبل استخدامه للحكم على السريان.

## Deployment Candidate
- `backend_app.py`: تطبيق FastAPI موحد.
- CORS مضبوط من متغير `ALLOWED_ORIGINS`.
- `/health` لاختبار الاستضافة.
- `MONITOR_TOKEN` لحماية تشغيل الرصد.
- `config.js` لوضع رابط Backend بعد نشره دون تعديل منطق الواجهة.
- `render.yaml` جاهز للاستضافة.
- GitHub Pages workflow موجود للواجهة.

## الخطوة التالية
رفع هذه النسخة إلى GitHub، تفعيل GitHub Pages، نشر Backend، ثم وضع رابط Backend في `config.js` وإجراء اختبار حي End-to-End.
