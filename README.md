# الراصد التشريعي — MVP v2 (البحث عند الطلب)

هذه النسخة تغيّر المنطق من تخزين اللوائح إلى وكيل بحث وتحليل عند الطلب.

## ما تم تنفيذه
- قائمة مصادر رسمية قابلة للاختيار المتعدد أو «الكل».
- هيئة الخبراء، المركز الوطني للوثائق والمحفوظات، أم القرى، وزارة المالية، الموارد البشرية، المحتوى المحلي، كفاءة الإنفاق، الحكومة الرقمية، الأمن السيبراني، سدايا، الديوان العام للمحاسبة.
- تحليل رابط رسمي وربط النتيجة بالمصدر.
- واجهة عربية RTL أولية.
- endpoint لإخراج CSV قابل للفتح في Excel.
- حماية من تحليل رابط لا يتبع النطاق الرسمي للمصدر المختار.

## مهم
اكتشاف روابط النتائج تلقائيًا داخل كل موقع هو المرحلة التالية. النسخة الحالية لا تدّعي أنها تبحث الإنترنت من داخل FastAPI دون موصل بحث؛ endpoint `/search-links` يجهز روابط بحث مقيدة بالنطاق، و`/analyze` يحلل الروابط الرسمية الممررة له.
