# الراصد التشريعي — محرك البحث الاقتصادي v2

يعتمد على ثلاث طبقات دون استدعاء OpenAI في البحث الأساسي:
1. اكتشاف ويب حقيقي داخل النطاقات الحكومية المختارة مع توسيع الاستعلامات التشريعية.
2. فتح وقراءة صفحات HTML وملفات PDF الرسمية واستخراج النص منها.
3. تحليل برمجي وترتيب النتائج واستخراج أرقام المواد والقرارات والتواريخ وإظهار المقاطع الأكثر صلة.

التصدير Word وExcel يستخدم النتيجة الحالية ولا يعيد البحث.

## Render
Build: `pip install -r requirements.txt`
Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`


## محرك البحث الحي
- يستخدم `TAVILY_API_KEY` إن كان موجودًا في Render.
- Tavily هو طبقة اكتشاف الويب الأساسية ومقيد بالنطاقات الحكومية المختارة.
- يستخدم `search_depth=basic` لتقليل الاستهلاك إلى الحد الاقتصادي.
- بعد اكتشاف النتائج يفتح الراصد الصفحة/ملف PDF الرسمي ويقرأ المحتوى مباشرة.
- إذا تعذر Tavily، ينتقل تلقائيًا إلى البحث العام المجاني كخطة احتياطية.
- لا يستخدم OpenAI API في البحث الأساسي.
