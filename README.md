# الراصد التشريعي — الإصدار 2.0

وكيل مبسط لمهمة واحدة: البحث عن نظام أو لائحة، مع إمكانية تحديد رقم مادة، ثم عرض ما يمكن إثباته عن التغييرات من مصدرين رسميين فقط:

1. هيئة الخبراء بمجلس الوزراء.
2. المركز الوطني للوثائق والمحفوظات.

## واجهة الاستخدام
- اسم النظام أو اللائحة: إلزامي.
- رقم المادة: اختياري.
- المخرجات: المادة، حالة وجود إشارة تعديل، مقتطف رسمي، رقم القرار وتاريخه عند استخراجهما، ورابط المصدر الرسمي.

## التشغيل
```bash
pip install -r requirements.txt
uvicorn backend_app:app --host 0.0.0.0 --port 8000
```

## ربط الواجهة
عدّل `config.js` وضع رابط خدمة Render:
```js
window.REGULATORY_API_BASE = "https://YOUR-RENDER-SERVICE.onrender.com";
```

## مبدأ الموثوقية
إذا لم يتمكن الراصد من إثبات النتيجة من المصدرين المحددين، يعرض أنه لم يجد نتيجة موثقة ولا يخمن تعديلًا.
