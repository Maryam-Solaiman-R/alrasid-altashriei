# الراصد التشريعي – MVP

نسخة أولية عملية مبنية على مصدرين أساسيين فقط:
1. هيئة الخبراء بمجلس الوزراء (laws.boe.gov.sa)
2. المركز الوطني للوثائق والمحفوظات (ncar.gov.sa)

## الفكرة
لا تبحث المنصة في المواقع الحكومية عند كل سؤال من المستخدم.
بدلاً من ذلك، تقوم طبقة "المصادر" بجلب وفهرسة الوثائق ثم تحويلها إلى نموذج موحّد:
- بيانات الوثيقة
- أدوات الإصدار
- المواد
- وثائق التعديل
- تاريخ السريان
- المصدر الرسمي

ثم يستخدم الراصد قاعدة البيانات المحلية للبحث، المقارنة، وإظهار النص الساري بتاريخ المعاملة.

## تشغيل محلي
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

ثم افتح:
http://127.0.0.1:8000/docs

## ملاحظة مهمة
محوّلات المصدرين مصممة بحيث يمكن ربطها مباشرة بالـ HTML/API الرسمي عند تشغيل المشروع
على Render أو بيئة متصلة بالإنترنت. يوجد fallback منظم لبيانات seed الموثقة لاختبار الواجهة
وقاعدة البيانات قبل تثبيت آلية الجلب النهائية.
